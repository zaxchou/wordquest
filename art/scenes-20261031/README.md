# WordQuest 纯场景背景（2026-10-31）

本批按最新提示词重新生成营地主页与 Boss 击败结算页的纯场景背景。每种场景独立生成 4 张，选 1 张；营地基于 v3 另做一次主角比例精修。保留全部 8 张候选与 1 张精修原图。

## 文件入口

- `camp-scene.png`：选定营地主页场景。
- `victory-scene.png`：选定结算页场景。
- `candidates/`：全部候选。
- `refinements/`：营地主角比例精修原图，约占画面高度35%。
- `index.html`：选定图与候选预览。
- `manifest.json`：原图尺寸、选择理由、SHA-256 和源图映射。
- `prompts.json`、`generation-log.json`：基础提示词与实际生成记录。

## 与上一批的区别

本批**没有告示牌、战报牌、面板、按钮、装饰性边框、文字、数字或 UI 图标**。天空、森林、草地和小径连续铺满整张画面。角色的木盾叶纹、Boss 的 X 形眼睛及环境星星/火花属于场景细节。

此前 `pages-20261031` 的带空白牌子与按钮方案仍作为历史参考保留。当前纯场景需求优先使用本批；面板、文字、按钮和交互由程序另行绘制。此处不提供烘焙到背景中的 UI 点击区域。

## 规格与接入

按 480×480 逻辑画布设计，保留高分辨率生成原图，实际尺寸见清单。原图是完整不透明场景，未进行图像缩放、调色、抠图或固件资源替换。本批未修改 GSP 场景、C 代码或设备运行资源，也未进行新的模拟器/真机验证。

营地要求主角位于篝火右侧、面向右；结算场景主角背对观众举剑、中央偏右为发光宝箱、右侧为败北树精。选择时检查无 UI、角色身份一致、场景关系及环境连续性。

生成工具为内置 image_gen，参考已确认战斗页与既有主角/Boss/宝箱精灵；战斗页中的所有 UI 均要求忽略。
