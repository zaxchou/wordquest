# WordQuest 无文字页面底图

本批新增两张页面：营地主页、Boss 击败结算页。每页独立生成 4 张候选，按与已确认战斗页一致的像素风格生成。

- `camp-home.png`：选定的营地主页。
- `boss-victory.png`：选定的结算页。
- `candidates/`：全部 8 张候选。
- `prompts.json`：实际基础提示词、参考图及逻辑画布说明。
- `manifest.json`：原图尺寸、选中候选、SHA-256、文字区域建议。
- `index.html`：分类预览和候选比较。

图内不含文字。等级、统计、按钮字均由设备实时渲染；告示牌、战报牌和按钮留白供程序叠字。结算牌留有三行文字空间，不绘制三条占位横线。

按 480×480 逻辑画布设计，交付保留高分辨率生成原图。具体原图尺寸见清单。文字叠加区域使用选定图视觉检查后的保守内边界，坐标以 480×480 为基准；应在设备缩放后再核对。

本批未处理 UI 代码、点击热区、字体、资源压缩、模拟器或设备验收。原有素材批次和 `processed-20261031` 目录独立保留。

生成工具：内置 image_gen。参考包括已确认战斗页、选定主角精灵、败北 Boss 精灵和打开的宝箱。参考图中的所有文字、血条与图标均要求不复制。
