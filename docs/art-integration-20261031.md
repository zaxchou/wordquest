## v7 要点（页面设计稿接入）

- **体积**：两页背景 JPEG 在 sim 渲染错位（弃用）；QOI 24/16 色全屏 +
  插图 384×120@48 色 + slash 统一单帧 → bundle 988KB < 1MB。
- **重大陷阱（已记入 memory）**：
  1. 同一 PNG 以非原生尺寸显示 → gspc 注册独立未压缩 store 资源（一图 110-150KB）；
     复用资源必须用原生尺寸。
  2. hidden overlay 的**非 button** 子件（image/label/container）会吞掉下层点击；
     button 类型豁免。设计上避免 hidden overlay 内子件覆盖可交互区。
  3. sim 交互测试的 Playwright 点击器坐标表从 v3 复制后一直错位
     （x=521 超出画布、y=402 落在提示按钮边框）——"点击失效"全是测试脚本问题，
     场景与真机触摸无辜。canvas rect 每次 resize 后必须重新读取。
- 结算统计、Boss 反击、营地数据（NVS `learned`）均为 v6 引入、v7 保留。
